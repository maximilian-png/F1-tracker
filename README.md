# JARVIS Moderation Bot

A Discord moderation bot designed to help manage a server.

## Commands

- `/ban` – Ban a member.
- `/kick` – Kick a member.
- `/mute` – Timeout a member.
- `/announce` – Send an announcement to a channel.

## Requirements

- Python 3.10 or newer
- discord.py

## Setup

1. Install the required dependencies.
2. Configure the Discord bot token as an environment variable named `DISCORD_TOKEN`.
3. Start the bot.

**Security:** Never share your bot token or upload it to GitHub.
